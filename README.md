🍝 Bella Vista Restaurant Website:-

A modern, responsive restaurant website built using HTML and CSS. This project showcases a beautiful UI for an Italian restaurant, including sections like menu, about, contact, and reservation form.


📌 Features:-
✅ Fixed navigation header
✅ Full-screen hero section with background image
✅ Menu section with styled food items
✅ About section with image and story
✅ Contact section with reservation form
✅ Responsive layout using Flexbox & Grid
✅ Smooth hover animations and transitions


🛠️ Technologies Used:-
1.HTML5
2.CSS3
3.Flexbox
4.CSS Grid


🚀 How to Run:-
1.Download or clone the repository
  "git clone https://github.com/your-username/bella-vista.git"
